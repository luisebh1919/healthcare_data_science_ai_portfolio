# Lab 05 — Paquete clínico y pruebas

La unidad reproducible es [clinlab](clinlab/README.md), con configuración en
`clinlab/pyproject.toml`, implementación en `clinlab/src/clinlab/` y pruebas en
`clinlab/tests/`. Se conserva esa raíz para mantener los imports y comandos del
laboratorio. Ejecutar las pruebas desde `lab05/clinlab/`.

El código compartido con Lab 06 es una instantánea académica idéntica; se conserva
en ambos laboratorios para que cada entrega sea independiente.
